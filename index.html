      About Sereia 🧜

      Sereia is a lightweight, privacy-focused Mermaid diagram editor that runs entirely in your browser.

      Key Features

      • 📝 Real-time Mermaid diagram editing and preview
      • 💾 Create savepoints to preserve diagram versions
      • 🎨 Multiple themes (Dark, Light, Forest, Neutral)
      • 📤 Export diagrams as PNG or SVG

      Privacy First

      All your data is stored locally in your browser. Nothing is sent to any server or cloud service. Your diagrams, savepoints, and settings remain private and accessible only on this device.

      Data is stored using IndexedDB via localForage. Clearing your browser data will remove all stored diagrams.
