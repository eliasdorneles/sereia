# Sereia 🧜

A lightweight, privacy-focused Mermaid diagram editor that runs entirely in your browser.

**[Use Sereia here](https://eliasdorneles.com/sereia/)**

No installation needed. Works completely offline after the first load.

## Features

- 📝 [Mermaid](https://mermaid.js.org/) diagram editing with live preview
- 📤 Export diagrams as PNG or SVG
- 💾 Create savepoints to preserve diagram versions
- 🔒 Privacy-first: All data stored locally in your browser
- 🎨 Multiple themes

## Privacy

Your diagrams, savepoints, and settings are stored locally on your device using [IndexedDB](https://en.wikipedia.org/wiki/IndexedDB).

Nothing is sent to any server or cloud service. Your data remains private and accessible only on your device.
